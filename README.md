# Сервис управления рассылками

Веб-приложение на Django для управления рассылками сообщений клиентам.

## Функциональность

### Управление данными
- CRUD для клиентов (Email, Ф. И. О., комментарий, владелец)
- CRUD для сообщений (тема, тело, владелец)
- CRUD для рассылок (дата начала/окончания, сообщение, получатели, владелец)
- Автоматическое заполнение владельца при создании объекта
- Динамический статус рассылки: «Создана», «Запущена», «Завершена»

### Отправка рассылок
- Ручной запуск рассылки с проверкой времени (`start_time <= now <= end_time`)
- Для каждого получателя создаётся запись в модели «Попытка рассылки» (через `bulk_create`)
- Статусы попыток: «Успешно», «Не успешно», сохраняется ответ почтового сервера

### Аутентификация
- Кастомная модель пользователя (`CustomUser`, вход по email)
- Регистрация с подтверждением email (письмо со ссылкой)
- Вход/выход
- Восстановление пароля

### Роли и права
- **Пользователь**: видит только свои клиенты, сообщения, рассылки и попытки
- **Менеджер** (группа «Менеджеры»): видит всё, но не может редактировать/удалять чужие объекты
- **Суперпользователь**: полный доступ

### Статистика и кеширование
- Главная страница: всего рассылок, активных рассылок, уникальных получателей, успешных/неуспешных попыток, отправленных сообщений
- Кеширование через Redis (`django-redis`): настройка `CACHES`, кеш статистики на главной, кеширование списков

## Технологии
- Python 3.14, Django 6.1
- PostgreSQL
- Redis (`django-redis`, `redis==7.4.0`)
- Bootstrap 5

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте и активируйте виртуальное окружение:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
## Установите зависимости:

```powershell
pip install -r requirements.txt
```

#### Создайте базу данных PostgreSQL mailing_db и пользователя.

#### Настройте подключение в config/settings.py (или через .env).

## Примените миграции:

```powershell
python manage.py migrate
```

## Создайте суперпользователя:

```powershell
python manage.py createsuperuser
```

###  Запустите Redis (redis-server.exe).

## Запустите сервер:

```powershell 
python manage.py runserver
```

## Тестирование ключевых сценариев

1. Регистрация пользователя → подтверждение email (письмо выводится в консоль) → вход.

2. Создание клиента, сообщения, рассылки.

3. Отправка рассылки — письма выводятся в консоль, попытки сохраняются в БД.

4. Вход под менеджером (группа «Менеджеры») — видит все данные, но не может редактировать чужие (403).

5. Проверка кеша:
```powershell
redis-cli
SELECT 1
KEYS *
TTL home_stats_1
```
